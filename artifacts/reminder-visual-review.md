# 签到提醒区域只读审查

## 当前结构

- `ReminderArea` 已经把“签到提醒”和时间按钮放在同一个 `.reminder-title` 纵向容器中；无需增加新板块或改动斜切卡片结构。
- 当前关闭态文案由 `timeLabel` 生成，为“提醒时间 HH:mm”，代码中已不需要、也不应再渲染“提醒已关闭”。
- 视觉上仍像独立一行的主要原因是 `.reminder-time` 使用 `min-height: 44px`、负 margin 和居中对齐，文字离标题偏远且占据整行高度。

## 最小 DOM / CSS 调整建议

1. DOM 保持现有层级，只在时间按钮内增加可选的文字包裹元素（例如 `.reminder-time-label`），方便把视觉文字与 44×44px 热区分离；不要新增状态说明节点。
2. 关闭态只显示：标题“签到提醒” + 次级行“提醒时间 HH:mm ›”；开启态显示“每天 HH:mm 提醒 ›”。
3. `.reminder-title` 使用约 `2px` 的纵向间距；标题保持 12px，时间视觉字号降至约 9–10px、行高 12px、字重 500、颜色略浅于标题。
4. 时间按钮仍保留至少 44px 高的透明热区，但让内部文字靠上对齐并紧贴标题下方；建议通过 `padding-top` 或内部文字元素定位实现，不要直接把按钮高度缩小到不足 44px。
5. `.reminder-top` 可将 `padding-top` 从 17px 微调到 14–15px；开关继续独立占 44×44px，避免时间入口误触开关。

## 375 / 390px 风险

- 斜切区域固定宽 164px，扣除左右 padding 后约 122px；标题列与 44px 开关同排，可用宽度较紧。时间文案必须保持 `white-space: nowrap`，且不应增大字号。
- “提醒时间 21:30 ›”在 9–10px 下可容纳；开启态“每天 21:30 提醒 ›”更长，允许时间按钮视觉文本在开关下方横向延伸，但不能与开关同一垂直区间重叠。
- 不建议缩小斜切区或改动 `clip-path`，否则 375px 下标题可能更靠近斜边；现有 34px 左内边距应保留。
- 验证时应分别点击时间文字左右边缘和开关，确认两个热区不重叠，并检查 20:00/21:30 两种宽度。
