## 布局分层

1. `z=0`：页面容器，上部暖黄→浅粉多点/线性渐变，约在 y=460 CSS px 附近融入 `#F9F8F6`。
2. `z=1`：英雄插图和星星光线。角色主体底部与签到卡顶边重叠约 5–6 CSS px。
3. `z=2`：签到卡白色外壳，遮住角色底部，形成“角色在卡片后”的穿插感。
4. `z=3`：卡片内部的异形提醒面板、奖励格、进度线、CTA。
5. `z=4`：Modal、邀请弹层、toast；应相对于手机页面容器定位，不要以整个桌面 viewport 定位。

## 特征形状

- 手机页面外轮廓在截图四角有约 27 CSS px 圆角，角外是黑色。桌面预览建议保留这一容器形状；真实移动端可通过 media query 取消外部黑边，但不能破坏 390 对照截图。
- 签到卡不是普通统一圆角矩形：右上提醒区左边由约 `(568,527)` 向 `(638,623)` 斜落，然后与下方白色主体衔接。
- 主卡右上的白色主体在 y≈623 处再开始一个小圆角，不应直接用普通 header 矩形替代。
- 奖励格约 46×52 CSS px，圆角约 7–8 px；前 3 格的边框约 1.2–1.5 px，内部还有浅粉底的约 3 px 内缩。
- CTA 是纯胶囊，无明显阴影；渐变上粉下珊瑚，边缘有轻微柔化，不宜加黑影。
